# Calculadora Python
## Tarefa do Curso Profissão Analista de Dados da EBAC

## Descrição

Consiste em um script que roda uma calculadora em python

## Objetivo

Uma calculadora capaz de operar nas quatro operações básicas (adição, subtração, multiplicação e divisão).

## Como rodar o script?

### Abra o arquivo python

python3 calculadora.py

### Execute pelo arquivo .sh

Dê a permissão:

chmod +x calculadora.sh

Execute:

./calculadora.sh
